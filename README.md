# Тайный Санта СПБ РО ВСКС · 2026/2027

Готовая статическая витрина для **GitHub Pages**, подключенная к уже созданной функции `santa-api` в Supabase.

## Загрузка

1. Создайте репозиторий GitHub, например `vsks-secret-santa-2026`.
2. Загрузите файлы `index.html`, `styles.css`, `script.js` и `.nojekyll` **в корень репозитория** (без внешней папки).
3. В `Settings → Pages` выберите `Deploy from a branch`, затем `main` и `/(root)`, сохраните.
4. После публикации откройте URL GitHub Pages и обновите страницу.

## Использование

- Участник вводит общий пароль (проверяется **на сервере**), ФИО и пожелания.
- Сервер выдаёт уникальный токен (персональная ссылка). Ссылка использует URL-фрагмент `#token=...`, чтобы токен не отправлялся в запросе на GitHub Pages.
- Участник **должен сохранить личную ссылку**: восстановление или повторная выдача токена в текущем API не предусмотрены.
- Организатор вводит отдельный пароль и видит участников; может закрыть регистрацию и провести жеребьёвку (один раз).
- После жеребьёвки личная ссылка показывает получателя и его пожелания.

## Технические ограничения и безопасность

- В браузере содержатся **только публичные** Project URL и Publishable key. Не добавляйте `sb_secret`, `service_role`, пароли в исходники GitHub.
- Функция `santa-api` и таблицы Supabase **должны существовать**. Проверка `status` уже выполнена пользователем (HTTP 200).
- Участники, потерявшие ссылку, не смогут вернуть её автоматически.
- Текущий серверный API не имеет устойчивого rate limiting на подбор паролей, одноразового восстановления ссылок и транзакционной блокировки жеребьёвки. Перед рассылкой широкой аудитории следует внедрить эти меры и протестировать конкурентный запуск жеребьёвки.
- `status` открыто показывает число участников и состояние игры; обычные посетители не получают список ФИО.
- Общий пароль дает право зарегистрироваться, **не** означает личную аутентификацию.
- Не выкладывайте настоящий общий пароль в публичный README и исходники. В Supabase Secrets он уже хранится.
- Персональная ссылка является секретом: её обладатель может посмотреть результат. Не отправляйте её в общие чаты.

## Структура

- `index.html` — страницы игры;
- `styles.css` — оформление;
- `script.js` — обращения к Supabase Edge Function;
- `.nojekyll` — публикация на GitHub Pages.

## Проверка до старта

1. Зайдите в игру как тестовый участник и сохраните ссылку.
2. Проверьте статус по ссылке в инкогнито или на другом устройстве.
3. Проверьте вход организатора и список анкет.
4. Не запускайте жеребьёвку на настоящих участниках до окончания регистрации.
